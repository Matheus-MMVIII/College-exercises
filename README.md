# College Exercises

A collection of Java exercises and academic assignments developed throughout my college studies.

This repository serves as a record of my progress while learning and practicing Java programming, from fundamental programming concepts to object-oriented programming, data structures, algorithms, and problem solving.

## Purpose

The main purpose of this repository is to document practical exercises developed during college and provide a history of my progression with Java.

The exercises focus on applying programming concepts through small, independent problems rather than building a single application.

## Topics Covered

Throughout the exercises, the repository covers concepts such as:

* Java fundamentals
* Variables and data types
* Conditional statements
* Loops
* Methods
* Arrays and collections
* Object-oriented programming
* Classes and objects
* Encapsulation
* Inheritance
* Polymorphism
* Interfaces
* Exception handling
* Data structures
* Algorithms
* Problem solving
* Basic software design

## Repository Structure

```text
College-exercises/
└── src/
    └── ...
```

The `src` directory contains the Java source code organized according to the exercises and academic activities.

Each exercise is intended to be relatively independent, allowing individual concepts to be studied and implemented without depending on a larger application.

## Learning Approach

The exercises are used to reinforce theoretical concepts through implementation.

The general progression follows:

```text
Programming Fundamentals
        |
        v
Control Flow
        |
        v
Methods and Data Structures
        |
        v
Object-Oriented Programming
        |
        v
Algorithms and Problem Solving
        |
        v
More Complex Java Applications
```
